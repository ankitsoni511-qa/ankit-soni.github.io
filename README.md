# Ankit Soni — SDET / QA Portfolio

GitHub Pages-ready personal portfolio based on the supplied CV.

## Publish on GitHub Pages

1. Create a GitHub repository named `YOUR-USERNAME.github.io`.
2. Upload `index.html`, `style.css`, and the `assets` folder.
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main`, and save.
4. Your site will be available at `https://YOUR-USERNAME.github.io/`.

The CV is stored at `assets/AnkitSoni_Sr_QA_Engineer_CV.pdf` and is linked from the Resume buttons.
